跑通你的第一个 agent

Lesson 1 · 第 1 周 · 约 90 分钟 · 绑定 Mission：从零基础到能独立造 AI Agent 的工程师

这课结束时，你会拿到

  • 一个能在你本机真实跑起来的 agent，它自己写代码算出答案，而不是瞎猜
  • 一个你自己写的工具，被这个 agent 调用成功
  • 一个不会把 API key 泄露到 GitHub 的项目骨架（这件事现在就要做对，晚了就麻烦）

先搞清三件事，两分钟

第一，agent 不是模型。模型是引擎，agent 是「用这个引擎驱动的一套循环」。模型只负责往下写一个 token，agent 负责：把任务喂给模型 → 拿到输出 → 执行 → 把结果再喂回去 → 直到任务完成。

第二，smolagents 的 CodeAgent 让模型写 Python 代码来调用工具，而不是输出 JSON 去调用。这是它跟大多数框架最大的不同，也是为什么选它入门——你本来就看得懂 Python，agent 的每一步你都能读懂。

第三，这段代码是在你本机执行的。不是云端，不是沙箱。所以第一课先关掉所有默认工具，只跑最干净的版本。

Step 1 · 建工程

在你的学习目录里建一个 Python 工程

cd /d D:\AI\workbuddy工作路径\2026-11-01-23-44-31\lab

进到你放代码的目录。已经在里面的话这条不用跑。

uv init

让 uv 生成工程骨架：一个 pyproject.toml（记录这个项目依赖哪些包）和一个空的源码目录。

uv add "smolagents[openai]"

下载安装 smolagents，外加连接模型必需的 openai 包。方括号里的 openai 叫「可选依赖」，不装它的话后面连模型会直接报 ModuleNotFoundError——这是新手最常卡的一步。

uv run python check_env.py

跑我已经给你写好的环境自检脚本。它不联网，只验证三件事：包能导入、agent 能创建、自定义工具能注册成功。三行全部打印出来才算过关。

装包太慢怎么办：如果你等了三分钟还没装完，是 PyPI 官方源太慢。我已经给你的 uv 配好了阿里云镜像，正常应该在 30 秒内装完。
为什么用 uv 而不是 pip：uv 一条命令搞定「建虚拟环境 + 装包 + 锁版本」，不会把你系统里的 Python 搞乱。你以后每个小项目都该这么做。

Step 2 · 拿一个免费的模型 key

你的机器连不上 HuggingFace，所以官方教程里的免 token 方案用不了。改用国产的 OpenAI 兼容接口，免费额度足够你学完整个课程。

你的 key 已经配好了：硅基流动的 key 我写进了 lab/.env（变量名 SILICONFLOW_API_KEY），今天不用再注册任何东西。智谱是备选：哪天硅基限流了，再去 open.bigmodel.cn 注册一个换上。

重装环境时才需要自己配：在 lab 目录新建 .env，内容一行：

SILICONFLOW_API_KEY=这里粘贴你的key

然后在同一个目录新建 .gitignore，写：

.env
.venv/
__pycache__/
这一步千万别跳。你的项目迟早要推到 GitHub，key 一旦提交上去，几分钟内就会被人扫走刷爆额度。.gitignore 的作用是让 git 永远忽略这些文件。写完用 git status 确认列表里看不到 .env 才算过关。

Step 3 · 跑通第一个 agent

hello_agent.py 我已经帮你建好了，长这样——你的任务是对照着读懂每一行，而不是照抄：

import os
from dotenv import load_dotenv
from smolagents import CodeAgent, OpenAIServerModel

load_dotenv()

model = OpenAIServerModel(
    model_id="Qwen/Qwen2.5-7B-Instruct",
    api_base="https://api.siliconflow.cn/v1",
    api_key=os.environ["SILICONFLOW_API_KEY"],
)

agent = CodeAgent(tools=[], model=model, add_base_tools=False)

agent.run("第 118 个斐波那契数是多少？")

跑它（我已经替你跑通过一次：agent 自己写了循环算出 2046711111473984623691759，三次调用共 6 秒）：

uv run python hello_agent.py

uv run 会自动用项目里的虚拟环境执行，不用你先 activate。

你会看到 agent 一步步输出：它写了什么代码、执行结果是什么、最后给出的答案。注意看它写的代码——这就是 CodeAgent 的核心：让模型用代码解决问题，而不是靠记忆猜一个数。

报错排查：如果报 KeyError: 'SILICONFLOW_API_KEY'，说明 .env 没读到，检查文件是不是叫 .env（前面那个点，Windows 记事本容易存成 .env.txt）。如果报连接错误，先看 NOTES.md 的网络限制说明。

Step 4 · 给它一个你自己的工具

没有工具的 agent 只是个会写代码的聊天机器人。加个工具试试——用一个你熟悉的场景，健身房数据：

from smolagents import CodeAgent, OpenAIServerModel, tool


@tool
def gym_count(city: str) -> str:
    """查询某个城市有多少家健身房。
    Args:
        city: 城市名，例如 深圳
    """
    data = {"深圳": 741, "广州": 506, "上海": 623}
    return f"{city}有 {data.get(city, '没有数据')} 家健身房"


agent = CodeAgent(tools=[gym_count], model=model, add_base_tools=False)

agent.run("深圳和广州的健身房加起来有多少家？")

三个关键点：

  • @tool 这个装饰器把它变成 agent 能调用的工具
  • 函数第一行 """...""" 不是注释，是给模型看的说明书——模型靠它决定什么时候调用、传什么参数。写不清楚，工具就永远不会被调用
  • 参数后面的 -> str 和 city: str 是类型标注，smolagents 靠它生成工具的参数表
