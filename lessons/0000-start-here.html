你的 Mission（为什么学）

你简历上所有 AI 经历都是「用 AI 工具干活」。这份学习要让你能独立从 0 造出一个带评测、能上线、能写出数字的 AI 系统，放到 GitHub 上当作品集，用它换一份 AI 工程师的工作。

开始前，把两个 key 备好

  1. 模型 key：智谱开放平台 注册后在「API Keys」复制，或 硅基流动。存进 lab/.env（第一课有写法）。
  2. GitHub token：生成页（勾 repo 权限）。拿到后发给你的 agent 老师，仓库直接推好。
