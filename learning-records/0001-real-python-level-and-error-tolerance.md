# John 的真实 Python 水平低于自评，第一课的命令要在「已就绪」语境下讲

2026-11-02 晚，第一课 Step 1 他跑 `uv init` 被提示 already initialized 就停下来问，
并自述「我其实 python 也只是小白」。结合之前信息修正认知：他能读懂 Python、
用 AI 写过脚本，但**没有亲手做过工程初始化这类操作，对「命令报错 vs 正常提示」没有判断力**。

对教学的改变：

1. 所有命令按「已就绪环境」来写——他已经跳过了从零搭建，课程要把 `uv init` 这类命令
   改述为「理解用 / 重装时用」，并预先标注哪些输出是正常的（如 already initialized）。
2. 每课开头给一条「现在立刻跑这一条」的命令，让他 30 秒内见到结果，建立信心后再讲概念。
3. 报错不可怕要反复灌输：他把任何非预期输出都当作失败停下来问，需要持续校准。
4. Evidence：他贴出 `uv init` 的完整报错 + 主动承认水平，说明他遇到问题会回来问——
   这个习惯是好的，继续保持。
